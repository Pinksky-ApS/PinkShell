# Cmdlets

- [`Add-PinkPermissionsToManagedIdentity`](Add-PinkPermissionsToManagedIdentity.md) - grant
  Microsoft Graph and/or SharePoint Online permissions to a managed identity.
- [`Add-PinkSitesSelectedPermissionToSite`](Add-PinkSitesSelectedPermissionToSite.md) -
  grant an application read or write access to one SharePoint site via `Sites.Selected`.
